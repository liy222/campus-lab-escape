## Preserved harness findings and corrections

All failed directories above remain append-only. No product fix or Owner retest was needed. The QA corrections were:

1. Explicit `contextlib.closing` for fixture SQLite connections; Python's connection transaction context manager did not close handles, causing Windows cleanup errors.
2. A hash-string match against three digits was removed; hidden-content checks retained actual clue/description/argument content.
3. Old AI revision responses correctly remove any proposal card; the browser expectation was changed from “disabled button remains” to “card absent”.
4. Extremely short total deadlines correctly stopped after one call under OS scheduling; fake runtime monotonic time replaced the invalid assumption that two calls must start.
5. Legacy R1/M2 three-digit scans matched minted IDs. `semantic_text` now excludes exactly `session_id`, `generation`, `source_generation`, `event_id`, `request_id`, `turn_id`, `proposal_id`, `message_sha256`, `expires_at`, `saved_at` (ten tracking fields). It preserves all other fields, including error.message, descriptions, clue text, answers, summaries and tool arguments. Full responses remain unaltered in evidence and are independently schema/token checked. Affected tests are R1 A04/A10 and M2 R2 wrong-code/R3 wrong-panel; all reran in the final 46-test API and checker pass. This narrow exclusion does not claim arbitrary information embedded in legitimate identifiers could never be a covert channel.
