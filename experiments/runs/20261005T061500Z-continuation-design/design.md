`experiment_hashes()` includes every new non-excluded file under experiments/. Simply adding `experiments/continuation.py` changes `frozen()`; unchanged `runner.new_run()` and `runner.execute()` then reject a plan carrying original f443 freeze. The ordinary runner CLI constructs all72 rows and is unsuitable. Do not silently add a root module, exclude it with a monkeypatch or change any frozen source.
