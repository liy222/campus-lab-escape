## 交付与原因

每类制作三张不同房间背景（主区域、资料/准备区、管理/控制区），两种专属资料外观和一套主题终端的未完成/完成状态，第一批计划28张新原图。钥匙、普通柜体、供电箱和通用控制板沿用已认可的中性手绘物件；每包仍覆盖六类公开角色及必要状态，清单逐项注明独立制作或共享，不能声称全部重画。特写共用高分原图。

沿用已认可的柔和水粉/彩铅手绘、正面固定视角，背景留出真实台面和地面槽位，素材不绘制答案、密码、可读线索或新的必需操作。三个背景根据原有neutral_lab/archive/control映射；新素材不会决定机械规则。动态显现、状态切换和URL贴图加载继续复用SP-01修复。

仅在主题明确信号匹配时使用对应包，模糊或未覆盖主题保留现有通用回退。支持有限主题库不等于任意文字都具备专属场景；不随机改变同一关卡已确定的外观。创建页覆盖说明改为实际包说明，消除仅天文社的写死文字。
