# 五类主题内部美术变化扩充

基线bf434ed。用户要求继续增加素材，依据已标出的改进方向，本轮扩充既有天文社、图书馆档案、化学实验室、计算机机房、校园广播室内部变化。

## 本批成品

计划31张新原图：五主题各3个房间背景候选（15），各1款记录资料（5），天文星图1、共享封存资料1、共享钥匙1，另共享终端/柜体/线路箱/控制板四类新外观各default/completed一对（8）。成对状态用于同一设备，不把两态计为两个独立设计。特写继续共用高分原图。保留所有旧原图。

背景候选具有独立槽位布局，不只换色。每类房间从原背景与新背景中固定选一个；数据中的物件功能、依赖、谜面和通道权限不变。记录资料按名字语义先选logbook/sealed-note/star-chart类别，再在同类别稳定选择；设备先固定外观family，再在同一family内随完成状态切换，避免完成时换成另一台机器。

## 稳定选择与兼容

复用公开Level.created_at和level_id，不增加后端字段或浏览器私有存储。每项新增候选记录available_from；创建时间早于该项开放时间的关卡继续使用旧候选，缺少/非法创建时间保留旧候选。新关卡以level_id和房间/物件的稳定标识选用符合时间的候选。之后再加素材时使用新的开放时间，已有关卡的候选集合保持不变。创建页封面和游戏内选择一致，刷新、同步、重载、读档不重新随机。

本批候选开放时间记录在阶段stage.json。这个时间是素材选择元数据，不是付费授权、用户验收或新的封条流程。有限候选允许重复组合，不保证无限次生成永不重复。
