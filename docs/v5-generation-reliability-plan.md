# 关卡生成可靠性改进与有限真实采样

用户要求测试并改进关卡生成成功率。基线7b20e34，人工累计次数门已取消，但内容校验拒绝仍存在。本轮先修正生成提示与现有验收规则的表达差异，再用有限真实样本测量；实现与离线通过均不预填为真实成功率改善。

## 已知事实与改进

最近三次真实任务的历史安全元数据只记录MODEL_INVALID_OUTPUT/narrative，未保存具体句子或名称；不能确认其确切细因，不能补造旧失败原稿。本轮源码发现旧提示要求装置名以某词为“主体”，校验实际要求合法词位于名称末尾；“门禁终端一号”等形式会被拒。这是可复现的表达缺口，不等于已定位三次历史失败。

程序从原校验词表导出每个puzzle的name_requirements：允许后缀、必须末尾结束、是否需要门禁词、门禁词表与合法示例；提示按该项规则创作主题名字，不在末尾增加编号、括号、标点或状态。故事继续不另造归位/归还/放回资料或钥匙义务。三类命名失败仅记录name_suffix/name_access/name_container，叙事guard继续narrative；不存或回显原句/名字。

原接受/拒绝谓词、严格JSON/槽位/schema、操作说明、可解证明、机械规则、存档、公开API及费用不放松。不加默认值、修稿、历史关卡替代、自动重试或新模型供应商。旧定义不重算，新内部内容版本仍2.0.0；只增加模型请求的说明元数据，不新增模型回复字段。
