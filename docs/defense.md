这份材料只整理可以从工程记录中核对的事实和答辩提示。它不是学生的个人陈述、实际游戏体验、签字或教师意见；请用你自己的话核对后再用于课程展示。

## 项目讲解顺序

1. 游戏由三间固定房间组成。玩家通过调查线索、组合道具和输入密码通关；规则真值保存在服务端。
2. AI 队友读取当前可见状态并给出受限建议。任何推进动作由玩家确认后才提交；幂等回执、版本冲突、会话隔离和单槽保存由工程契约约束。
3. CH01 把应急钥匙改成首次合法使用后消耗。后端拒绝隐藏目标和非法道具组合，重复请求返回原回执；恢复、并发确认和重启后的状态由 T30 在隔离本地环境中检查。
4. 当前 v2 与 `release/archives/baseline_v1/` 分开。启动 v2 显式指定 `./data/game-v2.sqlite`；独立 v1 使用 `./data/game-v1.sqlite`。这是避免新旧状态互相污染的操作约束。
