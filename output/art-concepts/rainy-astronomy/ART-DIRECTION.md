# 美术方向 · 雨夜天文社（rainy-astronomy）

版本：1.1.0。日期：2026-10-29。适用：`/art-themes/rainy-astronomy/` 与 `frontend/src/v5/` 的新版界面。

本说明是这一主题包的设计依据：背景、物件、特写、界面配色和排版都从这里取值。它是设计文档，不是运行截图，也不代表真人已经验收。

当前手绘资源采用内置imagegen重建的3张背景与12张物件/状态原图；场景与特写共用同一高分原图。原矢量版清单与运行结果保留为历史来源，当前交付见[手绘重建说明](handpainted-v2/README.md)。

## 1. 一句话氛围

雨夜的校园旧楼里，天文社的活动室没有锁门：窗上全是雨，桌上摊着旧观测记录，黄铜和旧木在台灯下发暖。玩家在这里找的是“封存的观测记录”，不是恐怖场景。

关键词：雨、夜、旧木、黄铜、暖灯、纸张、克制的神秘感。

## 2. 色彩

| 名称 | 值 | 用法 |
|---|---|---|
| 夜色 `night` | `#0b171f` / `#10222b` | 页面底、HUD、场景外框阴影 |
| 深青 `teal` | `#1f3a3a` / `#20303a` | 物件金属冷部、设备外壳 |
| 旧木 `wood` | `#5c4030` / `#7d5738` / `#3f2a1b` | 桌面、书架、柜体 |
| 纸张 `paper` | `#f2e7cf` / `#e6d8ba` | 面板、卡片、线索纸 |
| 纸张暗部 | `#cdbb97` | 分隔线、纸边 |
| 黄铜 `brass` | `#bd8f52` / `#ecd09a` / `#7d5c31` | 标题小字、边框、钥匙、旋钮 |
| 灯光 `lamp` | `#f4cd86` / `#ffe9b8` | 吊灯、光池、完成态暖光 |
| 警示 `danger` | `#a9553f` | 删除、失败 |
| 完成 `sage` | `#8ba08b` / `#a9d6a0` | 完成标记、接通状态 |

规则：场景以暗蓝绿为主，暖色只出现在灯、纸张和黄铜上；界面面板一律用纸色，避免整屏深色导致阅读疲劳。

## 3. 字体与层级

- 标题：`Georgia, 'Songti SC', 'Times New Roman', serif`，字距 0.03em。用于 `h1/h2`、房间标题、结算标题。
- 正文/控件：`'Microsoft YaHei', 'PingFang SC', system-ui`，常用正文与操作说明至少14px，行高1.8–1.95。
- 小标签 `kicker`：11px，字距 0.18em，黄铜色，用于分区（“校园探索 / 现场勘察”）。
- 常用正文与操作说明至少14px；短辅助标签可适当更小，不以缩小正文挤入布局。

## 4. 布局

- 电脑浏览器（检查1280×720、1920×1080）：顶部导航 → HUD（标题/房间/三个入口）→ 场景（16:9，最大 1180px）→ 场景脚注（房间描述 + 通道）→ 物品栏 / 故事。
- 所有可点击控件 ≥44×44 CSS px；页面不横向溢出。

## 5. 场景与物件的比例约定

- 逻辑画布 1600×900，与旧生成场景一致；`manifest.json` 的 `slot_layout` 给出每个背景 8 个落点：`x/y` 为物件底边中点，`height` 为期望显示高度上限，`hotspot` 为点击区域（同时用于 HTML 热点定位）。
- 物件按“高度 ≤ slot.height、宽度 ≤ hotspot 宽度”等比缩放，因此宽扁的钥匙不会被拉满整排。
- 前三格/后四格分别落在桌面与地面两条带子上；不同背景有各自的落点，但房间数、槽位上限和顺序不变。
- 背景在物件位置留空（桌面、地面、柜前），不预画钥匙/柜子/终端，避免叠加出两个同类物件。

## 6. 角色外观

| 角色 | 外观 | 状态 |
|---|---|---|
| note | 观测记录册（深绿布面、黄铜角、摊开手写页）/ 星图资料页（羊皮纸上的深蓝星图版）/ 封存便笺（牛皮纸信封 + 火漆） | 单一状态；按公开物件名称选择外观 |
| key | 黄铜钥匙 + 皮革标签（“天文社”） | 单一状态；取走后由服务端对象列表决定消失 |
| terminal | 木壳 + 黄铜面板的旧资料终端 | 默认黑屏 / 完成态亮起绿色星图 |
| cabinet | 玻璃门资料柜 | 默认关闭 / 完成态右门打开并透出暖光 |
| circuit | 壁挂式配电箱（四个陶瓷保险座 + 拨杆） | 默认拨杆 OFF / 完成态 ON + 指示灯亮 |
| panel | 立式黄铜顺序盘（四个圆形铭牌 + 指示灯） | 默认暗 / 完成态四个铭牌亮起并打勾 |

图中不写真实密码、线路方向、设备顺序或线索数值；铭牌上的符号只是装饰，实际符号由服务端数据在界面中渲染。

## 7. 界面元素

- 面板：纸色背景 + 顶部 5px 黄铜条 + 1px 深色描边 + 大阴影；关灯世界里的一块“档案纸”。
- 特写：深墨绿展柜凹槽（径向渐变 + 内阴影），物件居中、投影朝下。
- 按钮：深绿渐变底 + 黄铜描边；主按钮更亮；次级按钮（“再看一眼场景”）透明底。
- 热点：场景上的半透明圆角胶囊，左侧小黄铜点，已完成时点变绿并显示 ✓。
- 结算：场景上方压一层暗纱（保留场景轮廓），中间一张纸色结算卡，四项服务端统计 + 两个入口。
- 动效只用 150ms 的颜色/边框过渡；`prefers-reduced-motion` 下关闭。

## 8. 禁止与回退

- 不为视觉改造重写服务端背景ID、房间数、物件ID、谜题或存档格式。
- 不接受模型给出的任意图片 URL；主题图只从本地 `public/art-themes/` 读取。
- 未覆盖主题回退到原有通用手绘素材，并在创建页与场景说明中如实标注“通用画面”。
- 单张资源缺失时保留通用素材并提示重试，不把缺图说成已完成。
