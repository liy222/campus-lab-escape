# 手绘物品、特写与设备状态素材包

风格沿用用户认可的第一房间第三版：柔和哑光手绘，物件保留清楚的机械结构和材质细节。使用内置 image_gen 逐项生成，未使用外部付费 CLI 或 DeepSeek。原游戏素材、玩法和存档保持原样。

双击 [index.html](index.html) 可在浏览器查看素材，按房间筛选、搜索名称并放大原图。目录计数依据实际文件；未生成项会明确显示。完整索引为 [catalog.json](catalog.json)，生成范围与文件归属为 [plan.json](plan.json)。

## 内容

- 准备室：墙钟、实验记录、铭牌、显微镜空台与装入玻片、储物柜锁定/密码接受/打开/取走物品、门闩、保险丝、玻片、标签及隐藏照片。
- 设备实验室：电箱六阶段、电脑五阶段及各自特写、维护说明、隐藏维护签、研究纸条、门禁卡、托盘、工作台与普通门闩。
- 控制室：终检台空槽/纸条插入/终检/通过、出口锁定/刷卡接受/终检/解除门锁/打开及特写、设备对应表、返回门与结局背景。
- 分层背景：第一房间净背景，第二、第三房间断电与通电净背景，共五张，去掉交互物件以便后续独立叠加。

最终范围为 84 个对应素材（含 32 个特写视图），另有 5 张净背景。其中 80 个对应素材和 5 张净背景为本轮新图，4 个对应全景复用已有样稿。修正前的原图另行保留，不计入最终数量。

## 接入边界

这是独立美术素材包，不等于已经替换游戏画面。生成图的字体、符号、电路和设备坐标不作为规则来源。正式接入时需要使用准确文字与动态覆盖层、校准缩放及热点，随后验证路线和存档恢复。

柜内保险丝、标签、照片以及电脑托盘上的道具为单独图层。打开的柜壳可以没有物品；必须按状态添加内容，照片不能提前显示。电路板、终检台操作区和文档书写区可能留空，预留给现有准确内容。

`room2/r2_light_overlay_on.png` 是复用的通电全景样稿，**不是透明灯光覆盖层**。`backgrounds/` 才是本轮补齐的净背景。第二、第三房间光照沿用现有统一供电状态，环境通电与电脑启动、控制台激活分别处理。

生图能维持相近的同设备构图，但不保证像素级完全一致。透明图可能含柔和半透明投影，须根据房间光照检查。各房间 `report.json` 和单图提示词记录实际生成来源、校验结果及局限，不能以文件名推断已经通过游戏接入测试。

第三房间出口的独立状态图采用木门与金属锁件，已有全景样稿为金属门。后续接入应统一门体材质并校准位置；这些全景样稿不直接作为分层游戏背景。
