# 五类主题内部变化素材制作源

本批使用内置 imagegen 实际制作31张PNG原图：五主题各3张背景和1张记录本，另天文星图1张、共享封存资料1张、共享黄铜钥匙1张，四类共享设备的初始/完成状态8张。状态对属于同一设备设计。没有使用外部Key或CLI，没有项目生成/伙伴/评价器真实调用。

每个 `<theme>-<id>.json` 保存实际完整提示、输入参考、内置工具输出路径和项目目标路径；`assets.json` 保存复制后的尺寸、透明边界、字节数与原图摘要。运行画面只引用项目内 `frontend/public/art-themes/<theme>/variation-v1/`，不依赖用户缓存。原像素未二次加工，特写与场景共用同一原图。

`*-manifest-base.json` 是本阶段开始前manifest的兼容副本，不是新执行结果。`install_metadata.py` 将原图原样复制并安装候选元数据；背景上的分离桌面按实际图像分别标定落点。`build_gallery.py` 从当前manifest生成可离线打开的图集：86展示卡片，74个不同图片来源；共享素材重复展示不重复计为新原图。

新增候选的开放时间为2026-10-30T04:44:56.276Z。以关卡的公开创建时间筛选候选、以固定关卡/物件标识选择搭配；旧关卡、缺少或非法创建时间均保留旧候选。不修改后端、存档格式或浏览器私有状态。背景/布局候选每房型两套，设备外观每角色两款，有限组合仍可重复。
