# V5 — 登录与新进度隔离

V5 is being developed as a separate gameplay version. Its intended local database is `data/game-v5.sqlite`; it must not open or migrate the existing V3.4 database. V5 selection and implementation are in progress, and acceptance testing has not yet been recorded here.

## Launch

The new [V5 launcher](../启动新版.cmd) starts the production preview at `http://127.0.0.1:8001/` and opens the browser after its health check succeeds. It requires a previously built V5 frontend at `frontend/dist-v5/`. The launcher does not install dependencies, build automatically, delete data, or stop an unrelated process that owns either port. V5 host ports are fixed at backend `127.0.0.1:8001` and development frontend `127.0.0.1:5174`.

To run the frontend in development mode, use the project Python from the repository root:

```powershell
$env:PYTHONUTF8 = '1'
& 'C:\Users\liyh\.conda\envs\1\python.exe' -B -X utf8 -m scripts.run_v5 --dev --open-browser
```

The development UI is served at `http://127.0.0.1:5174/` and proxies API calls to `http://127.0.0.1:8001/`. Mock AI is selected by default.

QA or isolated development may pass `--database <temporary-directory>/game-v5.sqlite` together with `--dev`. The launcher rejects legacy database names and refuses existing files without the V5 version marker. The option is unavailable in production mode.

## Build and verification status

Build the V5 frontend explicitly from the repository root:

```powershell
$env:VITE_GAMEPLAY_VERSION = 'v5'
npm.cmd --prefix frontend run build
```

The Vite configuration directs this build to `frontend/dist-v5/`. No V5 QA result is claimed by this file. `scripts/check_v5.py` reports missing suites as `NOT_READY` (exit 2), and writes each invocation to a fresh run directory. Formal results and acceptance limits will be added after the V5 candidate and independent QA are complete.
