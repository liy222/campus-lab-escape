# V5 — 开发候选（未发布验收）

V5 是与经典版并存的本机开发候选，**尚未通过发布验收**。它使用 `data/game-v5.sqlite`，不会复用或迁移经典版的 `data/game-v3.4.sqlite`。经典启动器 `启动游戏.cmd` 和对应数据库继续保留。目前没有 V5 发布 tag、合并到 `main` 或部署记录。

## Launch

[V5 启动器](../启动新版.cmd)在健康检查成功后，打开 `http://127.0.0.1:8001/` 生产预览。启动前须已有 V5 前端构建产物 `frontend/dist-v5/`。启动器不会安装依赖、自动构建、删除数据或结束其他进程。后端和开发前端端口固定为 `127.0.0.1:8001` 与 `127.0.0.1:5174`。

如需运行开发模式前端，请在仓库根目录使用项目 Python：

```powershell
$env:PYTHONUTF8 = '1'
& 'C:\Users\liyh\.conda\envs\1\python.exe' -B -X utf8 -m scripts.run_v5 --dev --open-browser
```

开发界面地址为 `http://127.0.0.1:5174/`，API 请求代理至 `http://127.0.0.1:8001/`，默认选择 Mock AI。V5 本机账户仅属于这台电脑，不是云账户。经典玩法、已生成关卡和免费提示不需要 API Key；生成新关卡需要临时 BYOK Key。生成失败不会自动发起付费重试。

QA 或隔离开发可在 `--dev` 下传入 `--database <temporary-directory>/game-v5.sqlite`。启动器拒绝旧版数据库名称，也会拒绝缺少 V5 版本标记的已有文件。生产模式不可使用此选项。该选项仅用于隔离验证，不会更改用户默认数据库。

## 构建与验证状态

请在仓库根目录显式构建 V5 前端：

```powershell
$env:VITE_GAMEPLAY_VERSION = 'v5'
npm.cmd --prefix frontend run build
```

Vite 会将产物写入 `frontend/dist-v5/`。各范围检查见 [`scripts/check_v5.py`](../scripts/check_v5.py)；缺少测试套件时会报告 `NOT_READY`（退出码 2），不会报告为通过。

## 证据与当前限制

独立离线复核针对冻结开发候选及有限范围：38 项网页操作、存档与恢复、重载和后端进程重启，以及三种模拟视口下的布局检查。各项定向发现已在相应候选轮次关闭；不同轮次不能累加成一次全绿结果。[离线结果](../evidence/upgrade/v5.0/qa/final-offline-result.json)与[联合复核](../review/findings/v5-offline-joint.md)均明确指出，这些结果不能证明真实生成质量或整体发布验收。

第一轮真实样本运行调用模型 3 次：G1/G2/G3 均被拒绝，A1/A2 跳过。保守用量上界增量 ¥0.03128048（非供应商账单）；原有 3 条未知调用保持未知。详见[第一轮记录](../evidence/upgrade/v5.0/real-samples/result.json)及[独立复核](../review/findings/v5-real-samples-review.md)。第二轮经明确授权后实际调用模型 4 次：G1 是一间房间的 easy 关卡，实际以 8 个动作到达 EXIT；G2/G3 被拒绝；A1 因伙伴答复复用了公开资料标题中的 clue IDs 而被内容 guard 拒绝，A2 跳过。第二轮保守用量上界增量 ¥0.03340072（非供应商账单），详见[第二轮记录](../evidence/upgrade/v5.0/real-samples-round2/result.json)、[Main 执行复核](../evidence/upgrade/v5.0/real-samples-round2/main-execution-review.json)及[独立复核](../review/findings/v5-round2-real-review.md)。两轮使用不同源码候选，应分别记为第一轮 0/3、第二轮 1/3，不能合并为统一成功率或外推为多房间生成/真实伙伴质量验收。

其后 AI-only 的 403-source 候选在独立窄离线检查中 8 项通过（exit 0，0.40 秒，403 个源码文件稳定）。检查含合成 MockTransport；原始 A1 答复仍被拒绝、A2 未调用，因此不构成真实伙伴成功或真实复测。详见[QA 封存结果](../evidence/upgrade/v5.0/qa/round2-ai-fix-result.json)和[独立发现复核](../review/findings/v5-round2-ai-fix.md)。合成伙伴请求保守用量上界为 0.046688 元，低于 0.05 元上限；2000 字全四字节 Unicode 生成预算上界为 0.212808 元，超过 0.20 元上限，已验证会在传输与预算预留前拒绝。评价器 C1/C2/C3 有限声明已完成登记校验（53 个源码文件、9 个登记产物）。CLI precheck 以 exit 0 返回 READY、issues 为空；确定性判读以 exit 2 返回 3 项 `INSUFFICIENT_EVIDENCE`，表示缺少真实模型判读，不是产品测试失败，也不代表 PASS。由于存在 3 条历史未知调用，付费评价继续严格阻塞。本次 AI 窄修之后没有再次真实调用，也没有额外调用授权。已知边界还包括：两个冷启动标签页都没有 Cookie 时，可能需要手动刷新；当前素材目录较通用，并非大量定制校园美术。

V5 当前没有发布 tag、合并到 `main` 或部署记录。该开发候选尚未作为正式版本验收。

公开证据边界：一条合成账号失败日志包含临时测试Cookie，原件只在本地封存。仓库提供[明确脱敏的副本及原哈希说明](../evidence/upgrade/v5.0/qa/authmaterial/20261023T063608354079Z-3c340e58/public-output-redaction.json)，不会把脱敏副本冒充原始字节；原退出码与封存清单保持。评价器的有限登记没有引用这条敏感原日志。
