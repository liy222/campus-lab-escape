# 本轮有限评价标准

评价对象是31张新图与前端稳定选图，不评价真实AI生成质量或整体可玩性。

| Claim | 可观察结果 / 验证入口 | 限制 |
|---|---|---|
| 素材真实可用 | 新31源图、尺寸、物件透明区、bbox/布局有效；manifest路径存在 | 文件和透明区通过不等于审美合格 |
| 同主题有变化 | 五包每房型两背景；不同固定ID可选到不同背景/设备/同类资料；三房向量有多种搭配 | 有限样本与组合可重复，不承诺无限生成独特 |
| 设备身份连续 | 各设备先选family，完成后只换同family状态；只预载对应状态 | 不据此重证原机械规则 |
| 资料语义保持 | 先按现有名字确定纸本/封存/星图类别，再在已有类别中选图；无星图包沿用纸本回退 | 不新增主题或改后端文本 |
| 旧关卡兼容且选择稳定 | 旧/缺失/非法created_at不选新候选；实际微秒ISO时间可用；之后增加未来候选不改既有结果；代表性刷新外观一致 | 沿用公开level_id/created_at；不增加存档字段 |
| 图集可直接查看 | HTTP及file路径图片解码成功、86卡片/74独立图片来源、新31图齐全 | 静态图集不包含游戏动作 |
| 实际桌面效果 | 新布局与物件在桌面场景中可见，必要初始/完成态及1280×720、1920×1080截图 | Synthetic结果只证明受控画面，不是真实生成或本人验收 |
